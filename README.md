# The Rusty Lake Archive

Um site dedicado ao universo de Rusty Lake, reunindo informações sobre seus jogos, personagens, histórias e mistérios.

## Sobre o projeto

Este projeto foi desenvolvido como uma atividade acadêmica para praticar os conhecimentos de **HTML** e a criação de um site com múltiplas páginas conectadas por links.

A proposta é apresentar o universo de Rusty Lake de forma organizada, explorando seus jogos, personagens e a narrativa misteriosa que conecta a franquia.

## Páginas

O site possui as seguintes seções:

- **Home** — página inicial do projeto.
- **Jogos** — apresenta os jogos do universo Rusty Lake.
- **Ordem** — mostra a ordem dos jogos.
- **Personagens** — apresenta os principais personagens da franquia.
- **Universo** — explica elementos e acontecimentos do universo de Rusty Lake.
- **Sobre** — informações sobre o projeto.

## Objetivo

O objetivo do projeto é colocar em prática conceitos de HTML, como:

-Estrutura básica de uma página HTML;
-Utilização de títulos e parágrafos;
-Inserção de imagens;
-Criação de links;
-Navegação entre diferentes páginas;
-Organização de arquivos e pastas;
-Utilização de meta tags.

## Tema

O projeto é inspirado na franquia Rusty Lake, conhecida por seus jogos de enigmas, narrativa não linear,
personagens misteriosos e atmosfera surreal. A ideia do site é funcionar como um pequeno arquivo para
explorar e conhecer melhor esse universo.

Projeto acadêmico — Ciência da Computação
